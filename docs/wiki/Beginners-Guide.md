# Beginner's Guide

Edge is a hard mod. It puts a small computer in your body, and you program it yourself. This guide walks you through it in order, one question at a time. Each page is short and ends with a link to the next.

You don't need to know how to program. Page 4 starts from zero.

## How to read it

- **Try things as you go.** Every program here is complete: copy it into the editor (`edit <name>` in Edge), save with **Ctrl+S**, and run it.
- **Each program says what it needs** on its first line, such as `-- Needs LV2 and a socket.` If your gateway is lower, it won't install yet; [Why Level Up?](Why-Level-Up) explains how to get there.
- **The rest of the wiki is the rulebook.** This guide explains why things matter. The detailed pages ([Gateway and Resources](Gateway-and-Resources), [Cyber Combat](Cyber-Combat), [Kernels and Flaws](Kernels-and-Flaws)...) have every number.

Already know the basics? [Getting Started](Getting-Started) is the short version.
