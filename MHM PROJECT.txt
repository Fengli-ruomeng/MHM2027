MOD名字：MoreHarderMinecraft : Edge
此项目意图彻底修复MHM2025/2026的设计冗余和游戏玩法偏移
LBV

理论上不应该有世界观，但是为了方便编写这个东西的设计草稿所以还是写点吧
此项目意图给MC加入一个全新的战斗维度，并且尽可能贴合原版。并且会尽可能全方面提升Minecraft的难度（MC增强是MHM传统）

计划战斗维度：
每个玩家出生都拥有一个个人网关，默认等级0（LV0），此功能是使用本模组大多数新功能的基础。
个人网关是一个玩家解锁新功能的重要属性，最高为LV10网关（以及一个创造模式限定的LV11网关），以及一个特殊的LV-1网关。
网关等级并无特殊用途，只是部分驱动需要对应等级的网关才能安装。

各网关级别：
LV0 [默认网关] 拥有128MB-RAM 25TOPS算力 以及1GB的缓冲区 提供1个对应其网关等级的接口槽位
LV1/2/3 [初级网关] 拥有512MB-RAM 45/60/85TOPS算力 以及3/5/8GB缓冲区 提供2个对应其网关等级的接口槽位
LV4/5/6 [中级网关] 拥有1GB-RAM 100/120/135TOPS算力 以及10/10/15GB缓冲区 提供4个对应其网关等级的接口槽位 和1个专用过载式接口
LV7/8/9 [高级网关] 拥有4/7/10GB-RAM 155/175/195TOPS算力 以及20/30/50GB缓冲区 提供4个对应其网关等级的接口槽位 和1个专用过载式接口
LV10 [顶级网关] 拥有15GB-RAM 300TOPS算力 100GB缓冲区 提供8个对应其网关等级的接口槽位 和2个专用过载式接口
LV11 [创造网关] 拥有1TB-RAM 10000TOPS算力 10TB缓冲区 提供16个对应其网关等级的接口槽位 和8个专用过载式接口
LV-1 [无网关] 无RAM 0TOPS 0MB缓冲区 0接口

RAM：玩家的默认内存基础数值，使用标准的计算机1024进1单位。玩家编写的程序，或者是预设程序想要运行，都会消耗RAM。RAM的恢复依赖饱和度，同时一旦RAM归零，玩家会陷入无尽的凋零状态。直到RAM不再等于或者低于0。

TOPS：玩家的默认计算速率数值，借用现实的计量单位。程序的运行一般会要求玩家至少达到一定程度的TOPS才能运行，而运行程序本身也会消耗TOPS。但不同的是，一旦程序停止运行，TOPS就会缓慢的恢复。TOPS归零时所有程序都会停止运作，因此这要求玩家至少保留1TOPS。（只要还有空余TOPS，就不会影响程序运转。）

缓冲区：玩家的默认Cyber防御数值，一旦玩家遭受骇入，缓冲区会延缓玩家的骇入速度，或是在一些类DDOS攻击时提供防御空间。缓冲区的恢复依赖Cyber药水。一旦缓冲区归零，玩家骇入只需要大概破解此玩家自行定义的防御性程序即可。（若存在，则骇入成功后会强制要求玩家等待一段时间）

网关接口：玩家的物理世界（游戏时间）连接器。如果玩家想对身体进行修改，或者增加特殊的能力，需要连接特定的连接接口才能运作。此接口可以接入通用兼容器（提供程序接口），也可以插入预设程序（可在没有编写能力或者运行权限的情况下运行不属于此级别的修改能力）。

过载式接口：网关接口的激进版本，在几乎没有等级限制的情况下提供极其激进的修改接口，或者允许接入使用了极其激进的接口编写的预设程序。


核心玩法：
玩家会解锁一个独属于自己的终端。此时此终端只允许对自己进行操作。玩家可以输入一些指令查看自己的数值（这基本就是LV0能做的）
核心功能为玩家可以打开一个编写窗口，使用此游戏大幅简化过的一种特别的编程语言，完成一个特定的程序并进行保存，比如一些防御性代码（在其他玩家骇入时提供防御），进攻性代码（破解其他玩家的骇入的代码，获得对方终端权限后直接对其身体进行操作修改），调整代码（修改自己的数据，比如血量，特殊能力什么的）。
部分接口默认不开放，也无法调用。例如LV1会解锁一个接口，允许玩家修改自己的移动速度。但此接口在LV0下调用会报错。唯一使用的方法是安装含有LV1代码的LV0级别预设程序。预设程序的运行不检查其内部代码是否运行在拥有权限的终端上。但大多数预设程序的其内部代码的级别不会和使用要求级别相差超过大于等于1级。
过载式预设程序和普通的预设程序是一类东西，但过载式预设程序更像是个分类，其可能存在允许LV4调用LV9甚至是LV10级别的代码。这只是个分类，用于游戏平衡。其运作逻辑本质上是和普通预设程序一个东西。
每个程序都会计算出独特的内存消耗和TOPS需求及消耗。部分防御程序要求玩家常态运行（比如防暴力破解的程序，需要常运行才可生效）才可生效。因此允许出现一些长时间任务。部分进攻程序（比如针对防暴力破解的预设程序Yapo）也需要常态运行，直到玩家得到结果。进攻程序依赖TOPS来提升其效果，比如LV11的TOPS几乎可以无视一切等级的防御程序（除权限拒绝，LV11可以运行一些暴力破解权限的程序）。不过此平衡设计还在审查，但想法就是这个想法。也可以制作一些常态的身体修改代码，比如运行中的程序检测到血量减少就会增加移速的那种。
仍然在设计范围和平衡，，，



玩家的网关可以使用一系列特殊武器，诸如Alontesi进攻性武器，Yate防御性装备（一部分是做盔甲的，一部分是做剑锤等的，其实是一套，名字不太一样），以及Hasik工程用具。同时网关允许你对其他拥有网关的生物进行骇入等操作。
LV-1网关不允许使用特殊武装的同时，免疫所有的骇入操作。

**Mod Name:** MoreHarderMinecraft : Edge

**Project Objective:** Completely resolve the design bloat and gameplay drift accumulated in MHM 2025/2026.

Strictly speaking, it shouldn't need dedicated lore, but writing a conceptual backdrop helps ground the design draft.

This project aims to introduce an entirely new combat dimension to Minecraft while remaining as cohesive with vanilla mechanics as possible, all while comprehensively escalating overall difficulty (overhauling MC's challenge is core MHM tradition).

---

### Combat Dimension Overview

Every player spawns with a **Personal Gateway** at Level 0 (LV0). This gateway serves as the foundational framework required to utilize most of the mod’s new mechanics.

The Personal Gateway is a progression metric that governs capability unlocks, scaling from **LV0 to LV10**, alongside a Creative-exclusive **LV11 Gateway** and a specialized **LV-1 Gateway**. Gateway levels do not provide innate passive bonuses; instead, specific drivers, hooks, and hardware require a matching gateway tier to install.

### Gateway Tiers

* **LV0 [Default Gateway]:** 128 MB RAM | 25 TOPS Compute | 1 GB Buffer | 1 Standard Interface Slot (Tier-matched)
* **LV1 / LV2 / LV3 [Entry Gateway]:** 512 MB RAM | 45 / 60 / 85 TOPS Compute | 3 / 5 / 8 GB Buffer | 2 Standard Interface Slots (Tier-matched)
* **LV4 / LV5 / LV6 [Mid-Tier Gateway]:** 1 GB RAM | 100 / 120 / 135 TOPS Compute | 10 / 10 / 15 GB Buffer | 4 Standard Interface Slots (Tier-matched) + 1 Dedicated Overload Interface Slot
* **LV7 / LV8 / LV9 [Advanced Gateway]:** 4 / 7 / 10 GB RAM | 155 / 175 / 195 TOPS Compute | 20 / 30 / 50 GB Buffer | 4 Standard Interface Slots (Tier-matched) + 1 Dedicated Overload Interface Slot
* **LV10 [Apex Gateway]:** 15 GB RAM | 300 TOPS Compute | 100 GB Buffer | 8 Standard Interface Slots (Tier-matched) + 2 Dedicated Overload Interface Slots
* **LV11 [Creative Gateway]:** 1 TB RAM | 10,000 TOPS Compute | 10 TB Buffer | 16 Standard Interface Slots (Tier-matched) + 8 Dedicated Overload Interface Slots
* **LV-1 [Null Gateway]:** 0 RAM | 0 TOPS | 0 MB Buffer | 0 Interface Slots

---

### Core Gateway Attributes

* **RAM:** The player's base memory pool, adhering to standard binary computing increments (1024 base). Executing custom-written scripts or precompiled presets permanently occupies RAM while running. RAM regeneration is tied to hunger saturation. If RAM drops to zero or below, the player enters an endless **Wither** state until memory returns to positive values.
* **TOPS (Tera Operations Per Second):** The player's computational throughput metric. Programs require a minimum TOPS threshold to launch and consume continuous processing capacity while active. Unlike RAM, TOPS gradually restores once a program terminates. If available TOPS hits zero, all active processes crash immediately. Players must maintain at least 1 free TOPS to prevent thread collapse; as long as surplus TOPS exists, running tasks remain unaffected.
* **Buffer:** The player's baseline cyber-defense threshold. When subjected to intrusion attempts or DDoS-style attacks, the buffer absorbs damage and delays infiltration progress. Buffer recovery relies on Cyber Potions. Once the buffer is fully depleted, attackers only need to bypass the target's active custom defensive scripts (if present, a successful breach enforces a penalty delay on the victim).
* **Gateway Interface:** The physical-to-digital bridge for player modifications. Altering the player's biological parameters or binding special abilities requires connecting to an interface slot. Slots accept Universal Adapters (exposing raw script hooks) or precompiled **Preset Programs** (allowing players to run higher-tier modifications without coding knowledge or execution privileges).
* **Overload Interface:** A radical, volatile variant of standard interfaces. It bypasses conventional tier checks to expose high-risk modification hooks or execute aggressively compiled presets.

---

### Core Gameplay Loop

Players start with access to a personal Terminal. Initially, this terminal is strictly limited to local, self-targeted operations. Players can run diagnostic commands to inspect their hardware stats (essentially the limit of what LV0 can do).

The defining feature is the in-game script editor:

* Players write, compile, and save programs using a streamlined, mod-specific programming language.
* **Defensive Scripts:** Active firewalls and intrusion countermeasures against player hacks.
* **Offensive Scripts:** Decryption routines designed to crack external gateways, seize target terminal privileges, and directly alter the victim’s physical stats.
* **Modifier Scripts:** Self-enhancement scripts modifying parameters like maximum health, kinetic speed, or specialized passives.

Certain APIs remain locked by default. For example, an LV1 gateway unlocks the API responsible for movement speed modification; calling this hook on an LV0 terminal returns a syntax/runtime privilege error. The only workaround is mounting an LV0-compatible **Preset Program** containing precompiled LV1 logic. Preset programs bypass terminal execution-level checks, though most standard presets stay within a 1-tier delta between requirement and internal capability.

**Overload Presets** share identical underlying logic with standard presets, but serve as a high-risk balancing tier—for example, permitting an LV4 gateway to run LV9 or LV10 routines.

Every script dynamically calculates memory consumption and TOPS overhead:

* Certain defensive scripts must run as persistent background daemons (e.g., continuous anti-brute-force monitors).
* Offensive payloads (such as the anti-firewall routine *Yapo*) also run persistently until a breach succeeds.
* Offensive penetration scales directly with surplus TOPS (e.g., LV11 compute can overpower virtually all defense tiers, aside from total access denial, though LV11 can execute brute-force privilege escalation).
* Players can write event-driven modifier scripts, such as a background process that monitors health drops and instantly triggers a speed surge.

---

### Cyber Hardware & Interactions

Gateways interface with specialized weapon and equipment classifications:

* **Alontesi:** Dedicated offensive cyber-weaponry.
* **Yate:** Protective equipment suites (spanning cybernetic armor as well as defensive melee weapons like swords and maces—functionally an integrated set under varying nomenclatures).
* **Hasik:** Engineering and field utility tools.

Gateways also allow players to initiate cyberwarfare and intrusion against any non-player mob or entity equipped with a gateway.

**The LV-1 Gateway:** Strictly prevents the player from equipping or activating any cybernetic weaponry, but in return grants absolute immunity to all external hacking, intrusion, and cyber manipulation.
